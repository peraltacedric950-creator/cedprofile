JAMES CEDRIC M. PERALTA - GRAND LINE PHP PORTFOLIO
================================================

REQUIREMENTS
------------
- XAMPP
- Apache
- A modern web browser
- No MySQL is required for this version.

INSTALLATION
------------
1. Install XAMPP.
2. Open the XAMPP Control Panel.
3. Start Apache.
4. Put this entire "portfolio" folder inside:
   C:\xampp\htdocs\portfolio
5. Open:
   http://localhost/portfolio/

CONTACT FORM
------------
The form validates name, email, and message using PHP.
It intentionally does not require MySQL and does not send real email.
It displays a success message after valid submission.

NOTES

- The bounty values are fictional decorative elements.
- Skill percentages are student-level self-estimates.
- The design is One Piece-inspired rather than a copy of an official website.
